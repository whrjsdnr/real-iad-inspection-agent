# 한계

1. **3D 표면 투영은 근사 시각화**: 사용자 승인에 따른 표시용 투영이며, 실측 칙첩 extrinsics·CAD 정합이 아니다. `physical_alignment_verified=false`.
2. **HVQ 원시 맵 저장 범위**: 500시점·100제품·30품목뿐. 나머지 23,900제품은 스칼라 점수만 있다. 왜 100제품만 저장됐는지는 미확인.
3. **학습 데이터 구분**: 전체 24,000제품 집계는 Validation 포함이고, 실제 학습 목록과의 중복은 UNKNOWN — 참고 지표로만 사용. 대표 성능은 Test 3,593.
4. **Train NG 마스크 위치 분포**: 공간 히트맵의 분모는 Train NG 기반이며 제품 간 자세 정합을 거치지 않았다.
5. **소표본·미관측 영역**: 분모 MIN_DENOMINATOR 미만은 수치 대신 사유 표시. 미관측 셀은 투명 처리하고 정상으로 표기하지 않는다.
6. **운영 미검증 항목**: 운영 서버 재배포(신코드), 실브라우저·LAN 외부 접속, 실제 Qwen 대화 루프 장시간 안정성, GUI 추론 v2 E2E.
7. **과거 수치 혼용 금지**: 98.84% 등 정의 미확정 수치는 현재 결과와 같이 쓰지 않는다.

향후 개선: 운영 배포 승인 진행, HVQ 맵 확장 추론(자원·승인 필요), 물리 정합 근거 확보 시 국소 표면 투영 고도화, 실환경 운영 파일럿.
