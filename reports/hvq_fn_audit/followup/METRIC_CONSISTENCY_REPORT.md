## F1 0.7063의 정확한 정의
- 모델: HVQ 단독(교정 참고 — Validation 적합 임계값 36.0244, heatmap_mean 제품 최대값).
- 판정: 이진(보류 없음). 분모: 전체 24,000제품(hold/unknown 제외 없음 — 단독 참고 체계에는 보류가 없음).
- 혼동행렬: TP 11,795 / FN 613 / **FP 9,195** / TN 2,397.
- Binary F1 = 2·11,795 / (2·11,795 + 9,195 + 613) = 23,590 / 33,403 = **0.706330** — API 값과 소수점 이하 15자리까지 일치.

## "FP 6,976 → F1 0.7569" 가설이 성립하지 않는 이유
6,976은 상호보완성 집계에서 **RT가 동시에 양성이 아니었던 정상 제품의 HVQ 오탐 부분집합**(N_hvq_fp_only)이다.
HVQ 총 FP = N_both_fp(2,219) + N_hvq_fp_only(6,976) = **9,195**. 이전 감사 본문(Phase 8)의 "정상에서 HVQ 단독 오탐 6,976건"은 이 부분집합을 총 FP처럼 써서 발생한 오표기 → 본 문서와 함께 정정(정정 이력: CORRECTION_REPORT.md).
